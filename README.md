Shoe Store

A simple shoe shopping app built with React and CSS, featuring product cards and a functional shopping cart.

Features
- Displays shoes with images, names, and prices.
- Add products to the cart.
- Increase or decrease item quantities.
- Automatically updates the cart total.
- Responsive layout for smaller screens.

Tech Stack
- React
- JavaScript
- CSS

### How to Run
1. Run npm install.
2. Run npm run dev to start the app.
3. Make sure shoe images are placed in public/images/.
